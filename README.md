### About

A modern, single-page portfolio website for **Manoj Kumar Pola** — Full Stack Developer.

Built with pure HTML, CSS, and vanilla JavaScript — no build tooling required — and deployed via GitHub Pages.

**Features:**
- Dark theme with purple/violet glassmorphism design
- Canvas starfield background animation
- Scroll-reveal animations and 3D tilt effects on project cards
- Responsive layout (mobile, tablet, desktop)
- Sections: Hero · About · Skills · Experience · Projects · Education · Certifications · Contact
