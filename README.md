## ✨ Features

- **Animated Canvas Background** — Interactive particle network with mouse tracking
- **Typing Animation** — Dynamic role text with blinking cursor
- **Glass Morphism UI** — Modern glassmorphism cards and navigation
- **Smooth Scroll Reveal** — Intersection Observer-based section animations
- **3D Project Cards** — Mouse-tracked tilt effect on hover
- **Animated Skill Bars** — Progress bars with scroll-triggered animations
- **Responsive Design** — Fully responsive across all screen sizes
- **Contact Form** — Integrated with Formspree for message delivery
- **SEO Optimized** — Open Graph tags, sitemap, robots.txt, semantic HTML

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, animations, Grid & Flexbox
- **JavaScript** — Vanilla JS with no dependencies
- **Font Awesome** — Icon library
- **Google Fonts** — Inter, Poppins, Fira Code
